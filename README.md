# The Absurd Clause Contest

One original English sentence of at most 200 characters, written as a clause that could hide deep inside a terms-of-service agreement: "Clause 9.4: By accepting these Terms, the User agrees that any dispute shall be settled by the Company's office goldfish, whose decision is final, binding, and entirely silent." It opens as a perfectly ordinary dispute-resolution clause and only turns absurd at the arbitrator — an office goldfish whose rulings are final, binding, and entirely silent. `main.ts` (Node 22, standard library only) holds the clause as a constant, validates it against the gate rules (1–200 characters, a single line, no control characters, not only whitespace), then writes it to `entry.txt` under `/output` (or `$MAKEFUN_OUTPUT_DIR` when set).
